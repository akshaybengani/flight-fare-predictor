# Enriched features

Generated by `src/enrich.py` from `data/merged.parquet` (745,519 rows). 121 new columns. Cached source files live in `data/external/` (gitignored).

`o_` = origin city, `d_` = destination city (inserted after the group prefix, e.g. `wxa_o_tmax`). Observation (scrape) date = journey date - days_left (2022-02-11 assumed, 2023-01-15), a single day per scrape, so `fx_*_obs` features are constants within a scrape. A feature that is constant in a training frame is dropped by `train_v2.py`.

## Leakage notes

- `wxa_*` (actual weather on the journey date) is NOT knowable at booking time. Treat results with it as an upper bound.
- `wxl_*` uses only 2015-2021 data, so it is knowable at booking time.
- `fx_*` (journey date) is the realised market price on the flight date; `fx_*_obs` is knowable at booking time.
- `cal_*`, `fest_*`, `crk_*` are fixtures known in advance (cricket schedules are published ahead; here taken from played-match records).
